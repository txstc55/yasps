# Symbolic simulation without the combinatorial code

<p class="lead">YASPS lets you describe physical energies once, symbolically. It differentiates them, discovers the sparse global system, generates CUDA kernels, and solves the Newton system on the GPU.</p>

The central problem YASPS addresses is mixed parameterization. A world-space point might be a free vertex, part of an affine body, or generated by a cage. Traditional implementations often duplicate an energy for every combination. YASPS keeps one energy expression and preserves each value's path back to its actual degrees of freedom.

## What you write

```python
from yasps import attribute, scene

world = scene("demo")
body = world.addMesh("body")

vertices = body.addPrimitive("vertices", numInstances=n_vertices)
tets = body.addPrimitive("tets", numInstances=n_tets)

x = vertices.addAttribute("position", rows=3, cols=1)
x.updateValue(initial_positions)

x_rest = vertices.addConstant("rest_position", rows=3, cols=1)
x_rest.updateValue(rest_positions)

tet2v = tets.addConnectivity("tet2v", vertices, tet_indices, 4)
tet_x = tets.addAttribute("positions", through=tet2v, source=x)
tet_x_rest = tets.addAttribute(
    "rest_positions",
    through=tet2v,
    source=x_rest,
)

energy_expression = my_elastic_energy(tet_x_rest, tet_x)
elastic = tets.addAttribute("elastic", computed_attribute=energy_expression)

world.addEnergy(elastic, projection_method=2)
world.addMinimizeTarget([x])

direction = world.minimizeEnergy(tolerance=1e-6)[0]
x.updateValue(x.value - direction, deepCopy=True)
```

This code describes the model. YASPS owns the derivative generation, sparse placement, kernel compilation, and linear solve.

## What YASPS deliberately does not prescribe

YASPS returns the solution of `H Δx = g`; it does not negate the result. A Newton update therefore usually subtracts the returned segment. The framework also does not provide a universal collision detector, continuous collision detector, line search, or timestep policy. Those pieces depend on the geometry and parameterization and remain part of the application.
